# Operator Docs

Runbook for manual, operator-side setup that can't live in code — documented **as it is done**, in the same change that relies on it. Expected entries for this project:

- Vercel project creation, team/domain configuration, env vars
- DNS / domain cutover for `sharjeelafzaal.com`
- Third-party service setup (contact-form delivery, analytics, etc.)

Per-doc shape: **What it is / Why this shape / Click-path or CLI / Verification / Decisions / Cross-references.** Cross-link the feature/ADR/architecture doc that drove the step, and record any deviations from spec with the why.
