# Releases

Per-release scope documents, auto-generated by the `/release-index` skill from feature/fix/spike frontmatter. File naming: `<version>.md` (e.g., `1.0.0.md`).

- Regenerate before every promotion of `develop → main`.
- **Frozen after the release is tagged** — historical records, never edited retroactively.

Format and rules: see the `release-management` skill (`.claude/skills/release-management/`).
