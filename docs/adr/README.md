# Architecture Decision Records

ADRs capture **why** a significant technical decision was made — the context, the options considered, and the rationale. Once `Accepted`, an ADR is **immutable**; you never edit a published ADR — you write a new one that supersedes it if the decision changes. See the `adr` skill (`.claude/skills/adr/`) for the format and rules.
