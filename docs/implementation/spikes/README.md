# Spikes

Time-boxed experiments to answer a specific technical question before committing to an implementation, named `S###-<kebab-slug>.md` with monotonic numbering. Run on `spike/*` branches.

- The output is **knowledge**, not a shipping deliverable — spike code may be discarded.
- `ready` requires defined acceptance criteria; `done` requires **human approval** on the result.
- TDD does not apply.

Format and lifecycle: see the `spike-implementation` skill (`.claude/skills/spike-implementation/`).
